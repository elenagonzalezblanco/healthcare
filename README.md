## Identidad ELEVALOS

La interfaz ES/EN utiliza los originales proporcionados por Elena y sus derivados optimizados. Se conservan dominios, rutas, cookies, variables `PRIVIA_*`, identificadores y datos existentes por compatibilidad; el cambio no migra ni autoriza datos clinicos. Los originales estan en `images/brand/originals/`.

Regenerar con Pillow: `python scripts/build_brand_assets.py --source-dir images/brand/originals --output-dir images/brand`. Los favicon usan URLs versionadas; no se inventa un dominio nuevo.
